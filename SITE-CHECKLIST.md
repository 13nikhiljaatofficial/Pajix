# PAJIX — Launch & Change Map

## 1. Brand identity — CHANGE NOW
- Product name: `Pajix`
- Old name: `PDFForge` → remove everywhere
- Browser title: `Pajix — Files, without the friction.`
- Logo: custom geometric P + X-inspired mark in `index.html` / `style.css`
- Primary visual identity: deep charcoal + acid-lime + violet + cyan
- Typography: Manrope + DM Mono

## 2. Interface — CHANGE NOW
The interface intentionally does NOT use the previous white-card PDF converter layout.

New sections:
1. Sticky minimal navigation
2. Oversized editorial hero
3. Orbital file visual
4. Pajix Workspace
5. Distinct Convert and Organize cards
6. “More tools / next” roadmap strip
7. Local workspace / drag-drop area
8. Three-step Pajix Loop
9. Privacy-by-design section
10. Contact section

## 4. Legal / privacy — REVIEW BEFORE PUBLIC LAUNCH
The current privacy text describes the current browser-side processing model.
Before adding analytics, advertising, server uploads, accounts, cookies or external APIs, update the Privacy Policy accordingly.

Recommended future pages:
- `/privacy.html`
- `/terms.html`
- `/contact.html`

## 5. Monetization — ADD LATER
Possible order:
- Phase 1: free tools + real user testing
- Phase 2: privacy-friendly analytics if needed
- Phase 3: ads on high-traffic informational/tool pages
- Phase 4: Pajix Pro for higher limits, batch processing and advanced tools

Do not put aggressive ads inside the main upload workspace.

## 6. Future tools — ROADMAP ONLY IN THIS VERSION
- Compress PDF
- Split PDF
- PDF → JPG
- DOCX → PDF
- PPTX → PDF
- XLSX → PDF
- Image compressor
- Image converter

These are not falsely advertised as working in the current version.

## 7. Technical notes
- Current conversion/merge engine uses PDF-Lib from cdnjs.
- GitHub Pages can host this static version.
- No backend is required for the current two tools.
- If server-side tools are added later, the privacy wording must be changed.
